# LeetCode 图算法阶梯思路总结

图算法是面试高频硬核考点，核心在于**建模抽象**、**选对算法**、**写对细节**。本文梳理 6 大核心模型、判断指南、通用模板与必刷题单。

---

## 一、图的存储与基础定义

```python
# 1. 邻接表（最常用，稀疏图）
from collections import defaultdict
graph = defaultdict(list)
for u, v in edges:
    graph[u].append(v)
    graph[v].append(u)  # 无向图加这行

# 2. 邻接矩阵（稠密图、Floyd、判边 O(1)）
n = len(edges)
adj = [[0]*n for _ in range(n)]
for u, v in edges:
    adj[u][v] = adj[v][u] = 1

# 3. 边列表（Kruskal、Bellman-Ford）
edges = [(u, v, w), ...]
```

| 存储 | 空间 | 遍历邻居 | 判边存在 | 适用场景 |
|------|------|----------|----------|----------|
| 邻接表 | O(V+E) | O(deg) | O(deg) | 稀疏图、大部分题 |
| 邻接矩阵 | O(V²) | O(V) | O(1) | 稠密图、Floyd、传递闭包 |
| 边列表 | O(E) | - | - | Kruskal、Bellman-Ford |

## 三、通用模板（背诵级）

### 1. DFS 通用模板
```python
def dfs(node, parent=-1):
    visited.add(node)
    for nei in graph[node]:
        if nei == parent: continue  # 树/无向图防回头
        if nei in visited:
            # 发现环/回边处理
            continue
        dfs(nei, node)
    # 后序位置：拓扑序加入栈、强连通 lowlink 更新
```

### 2. BFS 通用模板（最短路/层序）
```python
from collections import deque

def bfs(start):
    q = deque([start])
    dist = {start: 0}  # 或 visited=set([start])
    while q:
        u = q.popleft()
        if u == target: return dist[u]
```

### 3. Dijkstra 模板（非负权单源最短路）
```python
import heapq

def dijkstra(start, n):
    dist = [inf] * n
    dist[start] = 0
    pq = [(0, start)]  # (dist, node)
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]: continue  # 延迟删除
        for v, w in graph[u]:
            if dist[v] > d + w:
                dist[v] = d + w
                heapq.heappush(pq, (dist[v], v))
    return dist
```

### 4. Bellman-Ford 模板（有负权/判负环）
```python
def bellman_ford(start, n, edges):
    dist = [inf] * n
    dist[start] = 0
    for _ in range(n - 1):
        updated = False
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                updated = True
        if not updated: break
    # 第 n 次松弛判负环
    for u, v, w in edges:
        if dist[u] + w < dist[v]:
            return None  # 存在负环
    return dist
```

### 5. 拓扑排序 BFS（Kahn 算法）
```python
def topological_sort(n, edges):
    indeg = [0] * n
    graph = [[] for _ in range(n)]
    for u, v in edges:
        graph[u].append(v)
        indeg[v] += 1
    q = deque([i for i in range(n) if indeg[i] == 0])
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == n else []  # 有环返回空
```

### 6. 并查集模板（路径压缩+按秩合并）
```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
        self.count = n
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx == ry: return False
        if self.rank[rx] < self.rank[ry]:
            self.parent[rx] = ry
        elif self.rank[rx] > self.rank[ry]:
            self.parent[ry] = rx
        else:
            self.parent[ry] = rx
            self.rank[rx] += 1
        self.count -= 1
        return True
    
    def connected(self, x, y):
        return self.find(x) == self.find(y)
```

### 7. Kruskal 最小生成树
```python
def kruskal(n, edges):
    edges.sort(key=lambda x: x[2])  # 按权重升序
    uf = UnionFind(n)
    mst_weight = 0
    for u, v, w in edges:
        if uf.union(u, v):
            mst_weight += w
    return mst_weight if uf.count == 1 else -1
```

### 8. Prim 最小生成树
```python
import heapq

def prim(n, graph):
    visited = [False] * n
    pq = [(0, 0)]  # (weight, node)
    mst_weight = 0
    while pq:
        w, u = heapq.heappop(pq)
        if visited[u]: continue
        visited[u] = True
        mst_weight += w
        for v, weight in graph[u]:
            if not visited[v]:
                heapq.heappush(pq, (weight, v))
    return mst_weight if all(visited) else -1
```

## 五、算法选择决策树

```
图问题
    │
    ├─ 无权/边权为 1 → BFS（最短路/层数/连通性）
    │
    ├─ 有权非负 → Dijkstra（单源）/ Floyd（多源/小 V）
    │
    ├─ 有负权/判负环 → Bellman-Ford / SPFA
    │
    ├─ 有向无环图(DAG) → 拓扑序+DP（最长路/计数/可达）
    │
    ├─ 连通性/动态加边/分量 → 并查集
    │
    ├─ 最小生成树 → Kruskal(稀疏/边列表) / Prim(稠密/邻接表)
    │
    ├─ 强连通分量 → Kosaraju(两次 DFS) / Tarjan(一次 DFS+栈)
    │
    ├─ 二分图判定 → BFS/DFS 染色
    │
    └─ 二分图最大匹配 → 匈牙利(O(VE)) / Hopcroft-Karp(O(√V E))
```

## 六、高频易错点速查表

| 易错点 | 正确做法 |
|--------|----------|
| **无向图 DFS 不防回头** | `if nei == parent: continue` 或 `visited` 集合 |
| **BFS 最短路未判重入队** | 入队时标记 `dist`/`visited`，而非出队时 |
| **Dijkstra 不做延迟删除** | `if d > dist[u]: continue` 跳过过期堆顶 |
| **Bellman-Ford 未判负环** | 第 n 轮松弛仍更新则有负环 |
| **拓扑排序未判环** | 结果长度 < n 说明有环 |
| **并查集未路径压缩** | `find` 中递归压缩 `parent[x] = find(parent[x])` |
| **Kruskal 未按权重排序** | 必须 `edges.sort(key=lambda x: x[2])` |
| **Prim 重复入堆未去重** | 出堆时 `if visited[u]: continue` |
| **有向图建图方向反** | 课程表 `[a,b]` 表示 b->a（b 是 a 的先修） |
| **矩阵建图坐标映射错** | `id = x * n + y`，`x = id // n, y = id % n` |
| **状态压缩图节点数爆炸** | 评估状态数，必要时用哈希表存访问态 |
| **多源最短路用多次 Dijkstra** | 加超级源点/反图跑一次 / Floyd（V≤400） |

| 算法 | 时间 | 空间 | 适用条件 |
|------|------|------|----------|
| DFS/BFS | O(V+E) | O(V) | 无权图遍历/最短路/连通性 |

## 八、面试实战技巧

1. **先确认图的类型**：有向/无向、有权/无权、是否有环、节点数边数规模
2. **选对算法再写码**：用决策树 10 秒定算法，别上来就写 DFS
3. **建模是关键**：
   - 矩阵 → 隐式图，四方向邻居
   - 字符串变换 → 单词图，预处理通配符/邻接表
   - 依赖关系 → 有向图，拓扑序
   - 分组合并 → 并查集
4. **模板背熟改参数**：Dijkstra/Bellman-Ford/拓扑/并查集/Kruskal/Prim 全背会
5. **细节决定成败**：
   - 无向图加双向边
   - 入度数组初始化
   - 堆延迟删除
   - 并查集路径压缩+按秩
6. **复杂度主动汇报**：写完代码主动说时空复杂度及适用条件
