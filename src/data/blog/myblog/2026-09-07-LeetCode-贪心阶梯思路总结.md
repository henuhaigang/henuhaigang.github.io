# LeetCode 贪心阶梯思路总结

贪心算法是**局部最优推导全局最优**的策略。核心不在写代码，而在**证明正确性**。本文梳理 6 大经典模型、证明套路、判断指南与必刷题单。

---

## 一、贪心核心判断指南

| 信号特征 | 可能是贪心 |
|----------|------------|
| **求最值（最多/最少/最大/最小）** | ✓ |
| **可分阶段决策，每阶段局部最优** | ✓ |
| **无后效性：当前选择不影响未来可行域** | ✓ |
| **可用「交换论证」/「反证法」/「数学归纳」证明** | ✓ |
| **典型场景：区间调度、分发、跳跃、加油、跳跃游戏** | ✓ |

> **警惕**：DP 能解的贪心不一定能解；贪心能解的 DP 往往过度杀鸡用牛刀。面试先想贪心，想不出证明再写 DP。

## 二、六大经典贪心模型

### 1. 区间调度/不重叠区间（按右端点排序）
**核心**：选结束最早的，留给后面最大空间  
**模板**：
```python
intervals.sort(key=lambda x: x[1])  # 按右端点升序
end = -inf
count = 0
for s, e in intervals:
    if s >= end:
        count += 1
        end = e
```
**题目**：435, 452, 646, 1353, 1751

---

### 2. 分发/分配问题（双排序/优先队列）
**核心**：最小满足最小 / 最大匹配最大  
**模板**：
```python
# 455. 分发饼干：孩子胃口 g，饼干 s
g.sort(); s.sort()
i = j = 0
while i < len(g) and j < len(s):
    if s[j] >= g[i]: i += 1; j += 1; count += 1
    else: j += 1
```
**题目**：455, 881, 1353, 1705, 2410, 2444

---

### 3. 跳跃/覆盖/加油（维护最远可达/当前覆盖）
**核心**：贪心扩展覆盖范围，或维护最优加油站  
**模板**：
```python
# 45. 跳跃游戏 II：最少跳跃次数
cur_end = 0
farthest = 0
jumps = 0
for i in range(len(nums) - 1):
    farthest = max(farthest, i + nums[i])
    if i == cur_end:
        jumps += 1
        cur_end = farthest

# 134. 加油站：总油量 >= 总消耗必有解
# 从头遍历，累加 gas[i]-cost[i]，若 < 0 则起点重置为 i+1
```
**题目**：45, 55, 134, 1029, 1665, 1775

---

### 4. 股票买卖/利润累加（峰谷法/状态机贪心）
**核心**：上升段全吃，下降段不碰  
**模板**：
```python
# 122. 买卖股票的最佳时机 II
profit = 0
for i in range(1, len(prices)):
    if prices[i] > prices[i-1]:
        profit += prices[i] - prices[i-1]

# 714. 含手续费：峰谷法调整
# cash = max(cash, hold + price - fee)
# hold = max(hold, cash - price)
```
**题目**：122, 714, 309, 188(DP), 123(DP)

---

### 5. 字符串/数组构造（局部最优构造全局最优）
**核心**：按规则排序拼接、或逐位贪心  
**模板**：
```python
# 179. 最大数：自定义排序 x+y > y+x
from functools import cmp_to_key
nums_str = list(map(str, nums))
nums_str.sort(key=cmp_to_key(lambda x, y: -1 if x+y > y+x else 1))

# 402. 移掉 K 位数字：单调栈贪心
stack = []
for c in num:
    while k and stack and stack[-1] > c:
        stack.pop(); k -= 1
    stack.append(c)
```
**题目**：179, 402, 321, 484, 1029, 1665

---

### 6. 任务调度/CPU 调度（优先队列/堆）
**核心**：最短任务优先 / 最早截止时间优先 / 最大收益优先  
**模板**：
```python
# 630. 课程表 III：按截止时间排序，大顶堆维护已选课程时长
courses.sort(key=lambda x: x[1])  # deadline
heap = []
total = 0
for dur, dl in courses:
    total += dur
    heappush(heap, -dur)
    if total > dl:
        total += heappop(heap)  # 弹出最长课程

# 1226. 哲学家进餐 / 2050. 并行课程 III 等拓扑+贪心
```
**题目**：630, 2050, 1226, 2444, 2627

## 三、三大证明套路（面试必会）

### 1. 交换论证
> **思路**：假设存在最优解 OPT 与贪心解 Greedy 不同，找到第一个不同的决策点，交换后不劣于 OPT，矛盾。
> **例**：435 区间调度——OPT 选了结束较晚的区间，换成贪心选的结束早的，后续可选空间更大，不减少总数。

### 2. 反证法
> **思路**：假设贪心解非最优，存在更优解，推导出矛盾（如资源不足、违反约束）。
> **例**：134 加油站——若从贪心起点出发失败，说明中间某段亏油，但总油>=总耗，矛盾。

### 3. 数学归纳 / 保持不变量
> **思路**：证明每一步贪心选择后，问题规模缩小但结构不变，子问题最优解+当前选择=全局最优。
> **例**：45 跳跃游戏 II——维护「当前跳跃次数内能到达的最远位置」，每次必须在当前覆盖范围内选下一跳最远点。

## 五、贪心 vs DP vs 回溯 判断决策树

```
求最值/可行性问题
    │
    ├─ 状态可由子问题推导，有重叠子问题 → DP
    │
    ├─ 需求所有方案/路径 → 回溯
    │
    └─ 可分阶段决策，局部最优 → 尝试贪心
           │
           ├─ 能否用「交换论证/反证法」证明？ → 能 → 贪心
           │
           └─ 证明不了/反例存在 → 改 DP/回溯
```

**经典反例**：
- 0-1 背包：贪心选单位价值最高 → 错（需 DP）
- 最短路径（有负权）：贪心 Dijkstra → 错（需 Bellman-Ford）
- 硬币找零（面额 1,3,4 凑 6）：贪心选 4+1+1=3 枚 → 错（最优 3+3=2 枚）

## 六、高频易错点速查表

| 易错点 | 正确做法 |
|--------|----------|
| **排序键写错** | 区间调度按**右端点**升序；分发按**需求/资源**同向升序 |
| **单调栈方向反了** | 402 移掉 K 位：维护**单调递增**栈（栈顶大于当前则弹） |
| **堆大小顶搞反** | 630 课程表 III：大顶堆存**已选课程时长**，超时弹最长 |
| **峰谷法漏处理最后一天** | 122 股票：遍历到 `n-1`，比较 `prices[i] > prices[i-1]` |
| **加油站起点重置逻辑错** | `tank < 0` 时 `start = i+1, tank = 0`，而非 `start = i` |
| **自定义排序 cmp_to_key 符号反** | `x+y > y+x` 返回 `-1` 表示 x 排前面 |
| **贪心证明不写** | 面试必口述证明思路：交换论证/反证法/不变量 |
| **边界条件漏判** | 空数组、单元素、全相同、刚好满足/刚好不满足 |
| **优先队列存对象 vs 值** | 需要额外信息存元组 `(deadline, duration)`，仅比较值存负值 |
| **浮点数精度** | 涉及除法/比率时用分数 `a/b > c/d` 等价 `a*d > c*b` 避免浮点 |

## 七、常用数据结构配合贪心

| 数据结构 | 贪心场景 | 操作复杂度 |
|----------|----------|------------|
| 排序数组 | 区间调度、分发、构造 | O(n log n) |
| 双指针 | 双向匹配、对撞贪心 | O(n) |
| 最小堆 | 最早结束/最小资源优先 | O(log n) |
| 最大堆 | 替换最大代价/最大收益 | O(log n) |
| 单调栈 | 移除 K 位/下一个更大元素 | O(n) |
| 双端队列 | 滑动窗口最值/单调队列优化 | O(1) |
| 哈希表/计数器 | 频次统计/分组贪心 | O(1) |

## 八、面试实战技巧

1. **先举小例子验证直觉**：3-5 个数据手推，确认贪心策略
2. **写出贪心选择准则**：如「按右端点排序」「维护最远可达」「最小堆选最早结束」
3. **必须口述证明**：交换论证 3 步——假设最优解不同、找第一个差异、交换不劣于原解
4. **代码简洁**：贪心代码通常 < 20 行，逻辑集中在排序键和循环判断
5. **边界先跑**：空输入、单元素、全合法、全不合法、刚好临界
6. **复杂度分析**：排序 O(n log n)、堆操作 O(n log k)、单调栈 O(n)
