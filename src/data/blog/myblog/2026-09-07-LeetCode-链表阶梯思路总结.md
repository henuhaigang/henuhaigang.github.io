# LeetCode 链表阶梯思路总结

链表是面试必考题型，**指针操作熟练度**直接决定通过率。本文梳理 6 大核心模式、必刷题单与避坑指南。

---

## 一、链表六大核心模式

| 模式 | 核心思想 | 适用场景 | 代表题目 |
|------|----------|----------|----------|
| **哨兵节点** | `dummy = ListNode(0, head)` 统一头节点处理 | 删除头节点、插入头部、返回新头 | 203, 82, 24, 25 |
| **双指针（快慢/前后）** | `fast` 走 k 步，`slow` 再同步；或 `fast` 走 2 步 `slow` 走 1 步 | 找中点、倒数第 k、判环、入环点 | 876, 19, 141, 142 |
| **原地反转** | `pre, cur = None, head` 循环 `cur.next, pre, cur = pre, cur, cur.next` | 反转整表、区间反转、K 组反转 | 206, 92, 25, 2487 |
| **归并/拆分** | 快慢找中点 → 递归/迭代归并 | 排序链表、合并 K 表 | 148, 23, 21 |
| **环形链表技巧** | Floyd 判环 + 数学推导入环点 | 判环、入环点、环长度 | 141, 142, 287 |
| **多指针穿针引线** | 维护 `pre, cur, nxt, tail` 等多指针协作 | 复杂重排、分组、奇偶分离 | 86, 328, 725 |

## 二、必会基础操作模板（背诵级）

### 1. 哨兵节点 + 遍历删除
```python
def removeElements(head, val):
    dummy = ListNode(0, head)
    pre, cur = dummy, head
    while cur:
        if cur.val == val:
            pre.next = cur.next
        else:
            pre = cur
        cur = cur.next
    return dummy.next
```

### 2. 双指针找中点（左中/右中）
```python
# 偶数节点返回左中点：while fast.next and fast.next.next
# 偶数节点返回右中点：while fast and fast.next
def middleNode(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow
```

### 3. 原地反转（迭代版）
```python
def reverseList(head):
    pre, cur = None, head
    while cur:
        cur.next, pre, cur = pre, cur, cur.next
    return pre
```

### 4. 递归反转
```python
def reverseList(head):
    if not head or not head.next:
        return head
    new_head = reverseList(head.next)
    head.next.next = head
    head.next = None
    return new_head
```

### 5. 合并两有序链表
```python
def mergeTwoLists(l1, l2):
    dummy = tail = ListNode(0)
    while l1 and l2:
        if l1.val < l2.val:
            tail.next, l1 = l1, l1.next
        else:
            tail.next, l2 = l2, l2.next
        tail = tail.next
    tail.next = l1 or l2
    return dummy.next
```

### 6. Floyd 判环 + 入环点
```python
def detectCycle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast:  # 相遇
            slow = head
            while slow is not fast:
                slow, fast = slow.next, fast.next
            return slow
    return None
```

## 四、高频易错点速查表

| 易错点 | 正确做法 |
|--------|----------|
| **删头节点没处理** | 始终用 `dummy = ListNode(0, head)`，返回 `dummy.next` |
| **反转后丢失后续节点** | 先保存 `nxt = cur.next`，再改 `cur.next` |
| **双指针循环条件写错** | 找中点：`while fast and fast.next`；倒数第 k：`for _ in range(k): fast=fast.next` 后 `while fast` |
| **区间反转边界混淆** | 找到 `left-1` 前驱 `pre` 和 `right` 后继 `nxt`，反转 `[left, right]` 后 `pre.next = new_head, old_head.next = nxt` |
| **K 组反转不足 k 个不反转** | 先走 k 步检查 `cur` 是否为 None，不足则直接返回 |
| **合并链表忘记收尾** | 循环结束后 `tail.next = l1 or l2` |
| **递归深度过大栈溢出** | 大数据量改用迭代；Python 默认递归限制 1000 |
| **判环时 fast 先走** | `slow, fast = head, head` 然后循环内先移动再判断，或 `while fast and fast.next:` 内移动 |
| **原地修改丢失引用** | 多用临时变量保存 `next`，操作顺序：断连→接新→移动指针 |
| **奇偶/分隔链表尾部未置 None** | 最后记得 `even_tail.next = None` / `tail.next = None` 断环 |

## 五、复杂度速记表

| 操作 | 时间 | 空间 | 备注 |
|------|------|------|------|
| 遍历/查找 | O(n) | O(1) | - |
| 插入/删除（给定前驱） | O(1) | O(1) | 需前驱指针 |
| 反转 | O(n) | O(1) 迭代 / O(n) 递归 | - |
| 归并排序 | O(n log n) | O(log n) 递归栈 / O(1) 迭代 | 链表最优排序 |
| 判环/入环点 | O(n) | O(1) | Floyd 算法 |
| 合并 K 表（堆） | O(N log k) | O(k) | N 总节点数 |
| 复制带随机指针 | O(n) | O(n) 哈希 / O(1) 原地 | - |

## 六、面试实战技巧

1. **先画图再写码**：链表题画 3-4 个节点演示指针变化，避免脑补出错
2. **边界先跑通**：空链表、单节点、两节点、头尾操作
3. **命名规范**：`pre/cur/nxt`、`slow/fast`、`left_pre/right_nxt`、`odd/even`、`small/large`
4. **原地 vs 新建**：优先原地 O(1) 空间，除非题目允许新建或需保留原结构
5. **递归三要素**：终止条件、单层逻辑、返回值含义
6. **复杂重排分三步**：切分 → 处理子链表 → 合并/拼接
7. **双向链表**：多维护 `prev` 指针，删除插入对称操作
