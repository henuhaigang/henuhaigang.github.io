# LeetCode 滑动窗口阶梯思路总结

滑动窗口是**双指针的进阶形态**，核心是**维护一个满足特定性质的区间 `[left, right]`**，利用单调性/约束条件在 O(n) 时间解决子数组/子串问题。本文梳理 4 大核心模式、判断决策树、通用模板与必刷题单。

---

## 一、滑动窗口四大核心模式

| 模式 | 窗口特征 | 移动策略 | 典型题目 |
|------|----------|----------|----------|
| **固定长度窗口** | 长度 k 固定/可推导 | 右扩一步 → 左缩一步，同步移动 | 567, 438, 239, 643, 1456 |
| **可变长度-单调约束** | 全正数/非负，求和/积 ≥ target | 右扩累加 → **while 满足条件** 左缩更新答案 | 209, 713, 862(前缀和+单调队列) |
| **可变长度-计数约束** | 字符串/数组，至多/恰好 K 种/频次 | 右扩计数 → **while 违规** 左缩恢复合法 | 3, 424, 1004, 904, 76, 567 |
| **单调队列优化** | 窗口内求最值/中位数 | 双端队列维护单调性，队头即最值 | 239, 480, 1425, 1438 |

## 二、判断决策树：到底用哪种滑动窗口？

```
子数组/子串问题
    │
    ├─ 窗口长度固定/可直接推导（如排列/定长子串/最大平均数）
    │      → 固定长度滑动窗口
    │
    └─ 窗口长度不固定
          │
          ├─ 数组全为正数/非负，目标是「和/积 ≥ target」求最短/最长
          │      → 单调约束滑动窗口（右扩左缩，while 循环收缩）
          │
          ├─ 数组含负数，或求「恰好 K 个不同值」
          │      → 前缀和 + 哈希表 / 恰好 K = 至多 K - 至多 K-1
          │
          ├─ 字符串匹配/排列/覆盖/至多 K 种字符/至多 K 次替换
          │      → 计数约束滑动窗口（need/window + valid / 计数器）
          │
          └─ 窗口内需实时查最值/中位数
                 → 单调队列 / 双堆 / 有序集合
```

## 三、通用模板（背诵级）

### 1. 固定长度窗口模板
```python
def fixed_window(s, k):
    n = len(s)
    if n < k: return 0  # 或 []
    # 初始化前 k 个
    window = Counter(s[:k])  # 或 sum/其他状态
    ans = check(window)
    for right in range(k, n):
        window[s[right]] += 1          # 右扩
        window[s[right - k]] -= 1      # 左缩
        if window[s[right - k]] == 0: del window[s[right - k]]
        ans = update(ans, check(window))
    return ans
```

### 2. 可变长度-单调约束模板（正数数组求和/积）
```python
def monotonic_window(nums, target):
    left = 0
    cur_sum = 0  # 或 cur_prod = 1
    ans = float('inf')  # 或 0
    for right, val in enumerate(nums):
        cur_sum += val  # 或 cur_prod *= val
        while cur_sum >= target:  # 单调性：左缩只会让 sum 变小
            ans = min(ans, right - left + 1)
            cur_sum -= nums[left]
            left += 1
    return ans if ans != float('inf') else 0
```

### 3. 可变长度-计数约束通用模板（字符串/至多 K 类）
```python
from collections import Counter, defaultdict

def counting_window(s, t):  # 76. 最小覆盖子串通用版
    need = Counter(t)
    window = defaultdict(int)
    left = 0
    valid = 0
    start, length = 0, float('inf')
    for right, c in enumerate(s):
        window[c] += 1
        if window[c] == need[c]:  # 刚好满足需求
            valid += 1
        while valid == len(need):  # 窗口已覆盖所有需求
            if right - left + 1 < length:
                start, length = left, right - left + 1
            d = s[left]
            if window[d] == need[d]:  # 即将不满足
                valid -= 1
            window[d] -= 1
            left += 1
    return "" if length == float('inf') else s[start:start+length]
```

### 4. 至多 K 个不同字符/1 替换通用模板
```python
def at_most_k(s, k):  # 904/424/1004 通用框架
    count = defaultdict(int)
    left = 0
    ans = 0
    for right, c in enumerate(s):
        count[c] += 1
        while len(count) > k:  # 或 count[0] > k 等违规条件
            count[s[left]] -= 1
            if count[s[left]] == 0: del count[s[left]]
            left += 1
        ans = max(ans, right - left + 1)
    return ans

def exactly_k(s, k):  # 恰好 K = 至多 K - 至多 K-1
    return at_most_k(s, k) - at_most_k(s, k - 1)
```

### 5. 单调队列模板（滑动窗口最大值）
```python
from collections import deque

def maxSlidingWindow(nums, k):
    q = deque()  # 存索引，值单调递减
    res = []
    for i, val in enumerate(nums):
        # 1. 入队：维护单调递减
        while q and nums[q[-1]] <= val:
            q.pop()
        q.append(i)
        # 2. 出队：队头超出窗口范围
        if q[0] <= i - k:
            q.popleft()
        # 3. 记录答案：窗口形成后（i >= k-1）
        if i >= k - 1:
            res.append(nums[q[0]])
    return res
```

## 五、核心技巧专题

### 1. 「恰好 K」=「至多 K」-「至多 K-1」
```python
def subarraysWithKDistinct(nums, k):
    return atMost(nums, k) - atMost(nums, k - 1)

def atMost(nums, k):
    count = Counter()
    left = ans = 0
    for right, x in enumerate(nums):
        count[x] += 1
        while len(count) > k:
            count[nums[left]] -= 1
            if count[nums[left]] == 0: del count[nums[left]]
            left += 1
        ans += right - left + 1  # 以 right 结尾的合法子数组数
    return ans
```

### 2. 最大频次技巧（424. 替换后的最长重复字符）
```python
# 窗口内最大频次字符的计数
max_freq = max(count.values())  # O(26) 可接受
# 或维护变量：
if count[c] > max_freq: max_freq = count[c]
# 窗口长度 - max_freq <= k 即合法
```

### 3. 单调队列三步法
```
入队：while q and nums[q[-1]] <= val: q.pop(); q.append(i)
出队：if q[0] <= i - k: q.popleft()
取值：if i >= k - 1: res.append(nums[q[0]])
```

### 4. 前缀和 + 单调队列（862. 含负数最短子数组）
```python
# 前缀和数组 P，求 P[j] - P[i] >= K 的最小 j-i
# 维护单调递增队列存索引
for j, pj in enumerate(P):
    while q and pj - P[q[0]] >= K: ans = min(ans, j - q.popleft())
    while q and pj <= P[q[-1]]: q.pop()
    q.append(j)
```

## 六、高频易错点速查表

| 易错点 | 正确做法 |
|--------|----------|
| **左边界收缩用 `if` 而非 `while`** | 必须 `while 条件满足:` 循环收缩，直到不满足 |
| **计数器更新顺序颠倒** | 右扩先加、更新 valid → 左缩先判断 valid、再减、再更新 valid |
| **固定窗口初始化越界** | 先检查 `n < k`，再初始化前 k 个元素 |
| **单调约束窗口用于含负数数组** | 含负数时单调性失效，需前缀和+单调队列/哈希表 |
| **单调队列存值而非索引** | 必须存索引，才能判断是否滑出窗口 |
| **单调队列单调方向反了** | 求最大值维护**单调递减**；求最小值维护**单调递增** |
| **恰好 K 直接滑动窗口** | 无法直接维护「恰好 K」，必须用「至多 K」差分 |
| **最大频次变量滞后** | 424 题中 `max_freq` 只增不减是正确的（窗口扩大时才可能增大） |
| **窗口状态定义不清** | 明确：窗口 `[left, right]` 闭区间，长度 `right-left+1` |
| **字符串题用数组 vs 哈希表** | 仅小写字母用 `[0]*26`，通用用 `defaultdict(int)`/`Counter` |

## 七、复杂度速记表

| 模式 | 时间 | 空间 | 适用条件 |
|------|------|------|----------|
| 固定窗口 | O(n) | O(k) | 长度固定 |
| 单调约束（正数） | O(n) | O(1) | 全正/非负，和/积单调 |
| 计数约束 | O(n) | O(字符集/种类数) | 至多 K 种/频次约束 |
| 单调队列 | O(n) | O(k) | 窗口最值/中位数 |
| 前缀和+单调队列 | O(n) | O(n) | 含负数求和约束 |
| 双堆/有序集合 | O(n log k) | O(k) | 窗口中位数/顺序统计量 |

## 八、面试实战技巧

1. **先画窗口状态图**：`[left, right]` 区间、计数器、valid 含义
2. **明确四要素**：
   - 什么时候**右扩**？（遍历 right）
   - 什么时候**左缩**？（while 违规/满足条件）
   - 什么时候**更新答案**？（满足条件时/每次右扩后）
   - 窗口**状态如何维护**？（计数器/sum/单调队列）
3. **边界先跑通**：空串、k=0、k>n、全合法/全不合法
4. **变量命名规范**：`need/window`、`count/freq`、`valid/satisfied`、`left/right`/`l/r`
5. **原地 vs 计数**：字符串题优先计数器，数组题视情况用 sum/prod
6. **单调队列口诀**：**进队尾删小/大，出队头判界，取队头得最值**

> **一句话总结**：滑动窗口的本质是**在线维护区间状态**，固定窗口靠同步移动，单调约束靠正数单调性 `while` 收缩，计数约束靠 `need/window/valid` 判断合法性，单调队列靠双端队列维护最值。搞清「窗口长度是否固定」「数组是否全正」「约束是计数还是和/积」，套对模板即可秒杀。
