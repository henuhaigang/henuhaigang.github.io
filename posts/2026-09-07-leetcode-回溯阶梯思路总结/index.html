LeetCode 回溯阶梯思路总结

回溯是暴力搜索的艺术，核心是决策树遍历 + 状态维护 + 剪枝。本文梳理通用框架、四大经典模型、剪枝技巧与必刷题单。

一、回溯通用框架（背诵级）

def backtrack(路径, 选择列表):
    if 满足结束条件:
        result.add(路径副本)
        return
    
    for 选择 in 选择列表:
        if 不合法(选择): continue  # 剪枝
        做选择(选择)                # 修改状态
        backtrack(新路径, 新选择列表)
        撤销选择(选择)              # 恢复状态

三要素：

  1. 路径：已做的选择（如 path、board）
  2. 选择列表：当前可做的选择（如 nums[i:]、空格位置、下一个数字）
  3. 结束条件：找到解/遍历完所有选择

二、四大经典模型

模型核心特征选择列表构造去重/剪枝关键典型题目
排列有序、元素不可重复使用start 索引或 used 数组used[i] 防重复使用46, 47, 60
组合无序、元素不可重复使用start 索引递增start 保证不回头77, 216, 39, 40
子集无序、每个元素选/不选start 索引递增start 保证不回头78, 90, 784
棋盘/图搜索二维网格、上下左右/八方向方向数组 [(0,1),(1,0)...]visited/原地标记79, 51, 52, 37, 130

三、核心去重/剪枝技巧

1. 排列去重（47. 全排列 II）

nums.sort()
used = [False] * len(nums)
def backtrack(path):
    if len(path) == len(nums):
        res.append(path[:])
        return
    for i in range(len(nums)):
        if used[i]: continue
        # 核心去重：同层相同值跳过
        if i > 0 and nums[i] == nums[i-1] and not used[i-1]:
            continue
        used[i] = True
        path.append(nums[i])
        backtrack(path)
        path.pop()
        used[i] = False

口诀：排序 + used 数组 + not used[i-1] 同层去重

2. 组合/子集去重（40. 组合总和 II / 90. 子集 II）

nums.sort()
def backtrack(start, path):
    res.append(path[:])  # 子集收集所有节点
    for i in range(start, len(nums)):
        # 核心去重：同层相同值跳过
        if i > start and nums[i] == nums[i-1]:
            continue
        path.append(nums[i])
        backtrack(i + 1, path)  # 组合/子集 i+1，排列 used
        path.pop()

口诀：排序 + start 索引 + i > start 同层去重

3. 可行性剪枝（39/216/77 等）

# 和超过 target 剪枝（正数数组）
if cur_sum > target: return

# 剩余元素不足凑齐 k 个剪枝
if len(path) + (n - start) < k: return

# 棋盘越界/已访问/不匹配剪枝
if not (0 <= x < m and 0 <= y < n) or visited[x][y] or board[x][y] != word[idx]:
    return

4. 最优性剪枝（51/52 N 皇后）

# 位运算加速列/主副对角线占用检查
cols, diag1, diag2 = 0, 0, 0
def backtrack(row):
    if row == n: return 1
    # 可用位置 = ~(cols | diag1 | diag2) & ((1<<n)-1)
    available = ~(cols | diag1 | diag2) & ((1 << n) - 1)
    count = 0
    while available:
        p = available & -available  # 取最低位 1
        available &= available - 1  # 清除最低位 1
        cols |= p
        diag1 |= (p << 1)
        diag2 |= (p >> 1)
        count += backtrack(row + 1)
        cols ^= p
        diag1 ^= (p << 1)
        diag2 ^= (p >> 1)
    return count

六、高频易错点速查表

易错点正确做法
引用传递导致结果全是同一个列表res.append(path[:]) 做浅拷贝，或 path.copy()
去重条件写错排列：not used[i-1]；组合/子集：i > start
可重复使用元素索引不变39 题 backtrack(i, ...)；40 题 backtrack(i+1, ...)
剪枝条件放错位置for 循环内 continue，递归入口 return
棋盘原地标记忘记恢复board[x][y] = '#' 递归后 board[x][y] = original
全局变量未重置多测试用例时在方法内初始化 res = []、used = [...]
递归深度超限Python 改 sys.setrecursionlimit 或转迭代/栈
浮点数精度误差24 点游戏用 abs(a - 24) < 1e-6 判断
大数字符串加法手写 add_strings 或用 Python 大整数
位运算优化不会用列 cols、主对角线 diag1、副对角线 diag2 分别用位掩码

八、面试实战技巧

  1. 先画决策树：小规模输入（n=3）画出前两层，确认选择列表、路径、结束条件
  2. 确定三要素：
    • path 存什么？（列表/字符串/棋盘）
    • start/used 怎么控制选择列表？
    • 什么时候加入 res？
  3. 去重口诀背熟：
    • 排列：sort + used + not used[i-1]
    • 组合/子集：sort + start + i > start
  4. 剪枝早做：循环里 continue，递归入口 return
  5. 状态恢复对称：append→pop、add→remove、=→恢复原值
  6. 位运算加速：N 皇后、数独、字母集合必会位掩码写法
  7. 记忆化搜索：若子问题重复（如 140、638），加 @lru_cache 或字典备忘录

一句话总结：回溯的本质是决策树的深度优先遍历，框架固定「路径+选择列表+结束条件」，排列用 used，组合/子集用 start，去重靠「排序+同层跳过」，剪枝靠「可行性+最优性」，棋盘靠「原地标记+方向数组」。把通用框架、两套去重口诀、位运算加速刻进肌肉记忆，见题画树、套模板、加剪枝，回溯题就稳了。
