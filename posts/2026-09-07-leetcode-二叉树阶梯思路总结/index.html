LeetCode 二叉树阶梯思路总结

二叉树是面试高频考点，递归思维与遍历变体是核心。本文梳理 4 大遍历体系、5 类核心题型、必刷题单与通用模板。

一、二叉树四大遍历体系（必须烂熟于心）

1. 深度优先遍历（DFS）—— 递归版

# 前序：根 → 左 → 右
def preorder(root):
    if not root: return
    process(root.val)
    preorder(root.left)
    preorder(root.right)

# 中序：左 → 根 → 右（BST 升序）
def inorder(root):
    if not root: return
    inorder(root.left)
    process(root.val)
    inorder(root.right)

# 后序：左 → 右 → 根（底-up 信息传递）
def postorder(root):
    if not root: return
    postorder(root.left)
    postorder(root.right)
    process(root.val)

2. DFS —— 迭代版（栈模拟）

# 前序：栈先压右再压左
def preorder_iter(root):
    if not root: return []
    stack, res = [root], []
    while stack:
        node = stack.pop()
        res.append(node.val)
        if node.right: stack.append(node.right)
        if node.left: stack.append(node.left)
    return res

# 中序：左尽头入栈
def inorder_iter(root):
    stack, res = [], []
    cur = root
    while cur or stack:
        while cur:
            stack.append(cur)
            cur = cur.left
        cur = stack.pop()
        res.append(cur.val)
        cur = cur.right
    return res

# 后序：前序根右左 → 反转
def postorder_iter(root):
    if not root: return []
    stack, res = [root], []
    while stack:
        node = stack.pop()
        res.append(node.val)
        if node.left: stack.append(node.left)
        if node.right: stack.append(node.right)
    return res[::-1]

3. 广度优先遍历（BFS）—— 层序遍历

from collections import deque

def level_order(root):
    if not root: return []
    q, res = deque([root]), []
    while q:
        level = []
        for _ in range(len(q)):
            node = q.popleft()
            level.append(node.val)
            if node.left: q.append(node.left)
            if node.right: q.append(node.right)
        res.append(level)
    return res

4. 统一迭代模板（带访问标记——通用性最强）

def traversal(root):
    if not root: return []
    stack, res = [(root, False)], []
    while stack:
        node, visited = stack.pop()
        if not node: continue
        if visited:
            res.append(node.val)  # 后序位置
        else:
            stack.append((node.right, False))
            stack.append((node.left, False))
            stack.append((node, True))  # 标记为已访问子节点
            # 前序位置：res.append(node.val) 放在这里
            # 中序位置：放在 left 和 right 之间
    return res

2. 自底向上返回值（后序位置处理）

def dfs(node):
    if not node: return base_info  # 如 0, -inf, True, None
    left_info = dfs(node.left)
    right_info = dfs(node.right)
    # 后序：根据左右子树信息计算当前节点信息
    cur_info = merge(left_info, right_info, node)
    update_global_answer(cur_info)  # 可选
    return cur_info

3. BST 区间约束模板

def isValidBST(root):
    def dfs(node, low, high):
        if not node: return True
        if not (low < node.val < high): return False
        return dfs(node.left, low, node.val) and dfs(node.right, node.val, high)
    return dfs(root, float('-inf'), float('inf'))

五、高频易错点速查表

易错点正确做法
最小深度单子树算错if not left: return right+1 等单子树特判，不能 min(left, right)+1
路径回溯忘记撤销path.append(val) → 递归 → path.pop()
前缀和哈希表忘记回溯cnt[cur_sum] += 1 → 递归 → cnt[cur_sum] -= 1
BST 验证用局部比较必须用「区间约束」或「中序前驱」，不能只比父节点
LCA 返回值语义不清明确：返回「找到的目标节点 / LCA / None」三态
构造树切片开销大用索引 (pre_l, pre_r, in_l, in_r) + 哈希表存中序索引，O(n) 时间
层序遍历层分隔符丢失for _ in range(len(q)) 固定当前层大小
Morris 遍历指针改错先找前驱 pre.right = cur，访问后恢复 pre.right = None
序列化空节点不标记必须用 # 或 null 标记空，否则反序列化歧义
递归深度超限Python 改 sys.setrecursionlimit 或改迭代/BFS

七、面试实战技巧

  1. 先确定遍历顺序：

    • 构造树/传参数 → 前序
    • 求性质/汇总信息/LCA/DP → 后序
    • BST 有序/第 K 小 → 中序
    • 层级/宽度/视图 → 层序

  2. 明确递归函数语义：写注释 return 以 node 为根的子树的 xxx

  3. 画图演示小树：3-5 节点树手推递归调用栈、返回值流向

  4. 双递归模式：

    • 外层遍历每个节点作为起点
    • 内层从该节点出发 DFS
    • 如 437 路径总和 III、543 直径

  5. 空间优化套路：

    • 递归 → 迭代栈
    • 栈 → Morris 遍历（仅中序/前序）
    • BFS 队列 → 利用 next 指针 O(1) 空间（完全二叉树）

  6. 树形 DP 状态设计：

    • 打家劫舍：dp[node][0/1]
    • 监控二叉树：三状态贪心
    • 最大 BST 子树：返回 [isBST, min, max, sum, size]

一句话总结：二叉树的本质是递归分治，前序「根左右」构造/传参，后序「左右根」汇总/判定，中序「左根右」BST 有序，层序「逐层」视图/宽度。把 4 种遍历、2 种递归框架、5 大题型模型刻进肌肉记忆，见题先问「要不要回溯」「要不要自底向上」「是不是 BST」，二叉树题就稳了。
