LeetCode 链表阶梯思路总结

链表是面试必考题型，指针操作熟练度直接决定通过率。本文梳理 6 大核心模式、必刷题单与避坑指南。

二、必会基础操作模板（背诵级）

1. 哨兵节点 + 遍历删除

def removeElements(head, val):
    dummy = ListNode(0, head)
    pre, cur = dummy, head
    while cur:
        if cur.val == val:
            pre.next = cur.next
        else:
            pre = cur
        cur = cur.next
    return dummy.next

2. 双指针找中点（左中/右中）

# 偶数节点返回左中点：while fast.next and fast.next.next
# 偶数节点返回右中点：while fast and fast.next
def middleNode(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow

3. 原地反转（迭代版）

def reverseList(head):
    pre, cur = None, head
    while cur:
        cur.next, pre, cur = pre, cur, cur.next
    return pre

4. 递归反转

def reverseList(head):
    if not head or not head.next:
        return head
    new_head = reverseList(head.next)
    head.next.next = head
    head.next = None
    return new_head

5. 合并两有序链表

def mergeTwoLists(l1, l2):
    dummy = tail = ListNode(0)
    while l1 and l2:
        if l1.val < l2.val:
            tail.next, l1 = l1, l1.next
        else:
            tail.next, l2 = l2, l2.next
        tail = tail.next
    tail.next = l1 or l2
    return dummy.next

6. Floyd 判环 + 入环点

def detectCycle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast:  # 相遇
            slow = head
            while slow is not fast:
                slow, fast = slow.next, fast.next
            return slow
    return None

四、高频易错点速查表

易错点正确做法
删头节点没处理始终用 dummy = ListNode(0, head)，返回 dummy.next
反转后丢失后续节点先保存 nxt = cur.next，再改 cur.next
双指针循环条件写错找中点：while fast and fast.next；倒数第 k：for _ in range(k): fast=fast.next 后 while fast
区间反转边界混淆找到 left-1 前驱 pre 和 right 后继 nxt，反转 [left, right] 后 pre.next = new_head, old_head.next = nxt
K 组反转不足 k 个不反转先走 k 步检查 cur 是否为 None，不足则直接返回
合并链表忘记收尾循环结束后 tail.next = l1 or l2
递归深度过大栈溢出大数据量改用迭代；Python 默认递归限制 1000
判环时 fast 先走slow, fast = head, head 然后循环内先移动再判断，或 while fast and fast.next: 内移动
原地修改丢失引用多用临时变量保存 next，操作顺序：断连→接新→移动指针
奇偶/分隔链表尾部未置 None最后记得 even_tail.next = None / tail.next = None 断环

六、面试实战技巧

  1. 先画图再写码：链表题画 3-4 个节点演示指针变化，避免脑补出错
  2. 边界先跑通：空链表、单节点、两节点、头尾操作
  3. 命名规范：pre/cur/nxt、slow/fast、left_pre/right_nxt、odd/even、small/large
  4. 原地 vs 新建：优先原地 O(1) 空间，除非题目允许新建或需保留原结构
  5. 递归三要素：终止条件、单层逻辑、返回值含义
  6. 复杂重排分三步：切分 → 处理子链表 → 合并/拼接
  7. 双向链表：多维护 prev 指针，删除插入对称操作

一句话总结：链表的本质是指针的穿针引线，哨兵节点统一边界，双指针解决定位，原地反转是核心基本功。把 6 大模式、6 个模板刻进肌肉记忆，见题拆解为「定位→断连→重连→收尾」四步，链表题就稳了。
