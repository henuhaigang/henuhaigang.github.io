LeetCode 动态规划阶梯思路总结

动态规划（DP）是算法面试的重中之重，核心在于状态定义、状态转移方程、初始化与计算顺序。本文按难度阶梯梳理核心模型与必刷题目。

一、DP 核心四步法

步骤关键点
1. 定义状态dp[i] 表示什么？通常是「以 i 结尾」「前 i 个」「容量为 i」的最优解
2. 找转移方程由小规模子问题推导大规模：dp[i] = f(dp[i-1], dp[i-2], ...)
3. 确定初始值dp[0]、dp[1] 等边界情况，直接决定正确性
4. 确定遍历顺序从小到大、从大到小、正序/逆序，保证依赖的子问题已算好

口诀：状态定义清，转移方程准，初始值对，顺序不乱。

二、五大核心模型（按推荐掌握顺序）

1. 线性 DP（入门必会）

特征：一维数组，状态只依赖前几个位置
经典题：

  • 70. 爬楼梯 —— dp[i] = dp[i-1] + dp[i-2]
  • 198. 打家劫舍 —— dp[i] = max(dp[i-1], dp[i-2] + nums[i])
  • 213. 打家劫舍 II —— 环形数组，分两种情况讨论
  • 337. 打家劫舍 III —— 树形 DP 入门

变形技巧：滚动数组优化空间到 O(1)

2. 背包 DP（核心难点）

特征：两层循环（物品/容量），决策是「选/不选」
三大类型：

类型遍历顺序典型题目
0-1 背包容量逆序416. 分割等和子集、474. 一和零
完全背包容量正序322. 零钱兑换、518. 零钱兑换 II
多重背包二进制拆分/单调队列面试较少考，了解即可

核心模板：

# 0-1 背包：容量逆序
for w, v in items:
    for j in range(C, w - 1, -1):
        dp[j] = max(dp[j], dp[j - w] + v)

# 完全背包：容量正序
for w, v in items:
    for j in range(w, C + 1):
        dp[j] = max(dp[j], dp[j - w] + v)

判断依据：

  • 求组合数（顺序无关）→ 先物品后容量
  • 求排列数（顺序有关）→ 先容量后物品

3. 区间 DP（中高阶）

特征：区间 [i, j]，枚举长度→起点→分割点
经典题：

  • 516. 最长回文子序列 —— dp[i][j] = dp[i+1][j-1] + 2 if s[i]==s[j]
  • 1039. 多边形三角剖分的最低得分
  • 1000. 合并石头的最低成本 —— 进阶：k 合并

遍历模板：

for length in range(2, n + 1):      # 枚举区间长度
    for i in range(n - length + 1): # 枚举左端点
        j = i + length - 1          # 右端点
        for k in range(i, j):       # 枚举分割点
            dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + cost)

4. 子序列/字符串 DP（高频考点）

特征：两字符串或单串子序列，dp[i][j] 表示前缀匹配
经典题：

  • 1143. 最长公共子序列 —— 模板题
  • 72. 编辑距离 —— 增删改三操作
  • 583. 两个字符串的删除操作
  • 115. 不同的子序列 —— dp[i][j] 表示 s 前 i 匹配 t 前 j 的方案数
  • 712. 两个字符串的最小ASCII删除和

LCS 通用转移：

if s1[i-1] == s2[j-1]:
    dp[i][j] = dp[i-1][j-1] + 1
else:
    dp[i][j] = max(dp[i-1][j], dp[i][j-1])

5. 状态压缩/位掩码 DP（难点/加分项）

特征：状态用二进制位表示，常用于「选/不选」「访问过/未访问」
经典题：

  • 980. 不同路径 III —— 回溯+记忆化
  • 864. 获取所有钥匙的最短路径 —— BFS + 状态压缩
  • 1681. 最小不兼容性 —— 硬题

四、常见坑点速查表

坑点解决方案
数组越界dp 数组开 n+1 或 n+2，哨兵位处理边界
初始值错误求最小值初始化 inf，求最大值初始化 -inf，计数型初始化 0，dp[0]=1
遍历顺序反了0-1 背包容量倒序，完全背包容量正序；区间 DP 按长度递增
状态定义不清写注释：dp[i] 确切含义，区分「以 i 结尾」vs「前 i 个」
空间优化过早先写二维/一维正确版，验证通过再优化滚动数组
重复计算/遗漏画依赖图：dp[i] 依赖谁？谁依赖 dp[i]？

五、DP vs 贪心 vs 回溯 判断指南

场景优先考虑
最优子结构 + 无后效性 + 重叠子问题DP
局部最优能推导全局最优（可证明）贪心
求所有方案/排列组合/可行性回溯/DFS
最短路径/拓扑序BFS/拓扑排序
区间最值/区间合并区间 DP/单调栈/线段树

六、复习清单（面试前过一遍）

  • 能手写 0-1/完全背包模板，不看代码
  • 能说清 dp[i][j] 在 LCS/编辑距离中的含义
  • 区间 DP 三层循环顺序能默写
  • 会判断「组合数」vs「排列数」遍历顺序
  • 会做空间优化（滚动数组/原地修改）
  • 会处理「环形」→ 拆成两个线性问题
  • 会处理「输出路径」→ 记录前驱/回溯复原
  • 理解「无后效性」含义：过去只通过当前状态影响未来

一句话总结：DP 的本质是穷举+剪枝+记忆，状态定义是灵魂，转移方程是骨架，初始化与顺序是血肉。多画表格、多手推小样例、多总结模型，才能从「看懂题解」进阶到「见题知模型」。
