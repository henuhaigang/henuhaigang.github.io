LeetCode 双指针阶梯思路总结

双指针是数组/链表/字符串题目的万能钥匙，核心在于利用有序性/单调性/对称性将 O(n²) 降为 O(n)。本文梳理 5 大核心模式、判断指南与必刷题单。

一、双指针五大核心模式

模式指针移动逻辑适用场景典型题目
左右指针（对撞）left=0, right=n-1，向中间收敛有序数组/字符串、对称性、两数之和、容器盛水167, 11, 15, 18, 42
快慢指针（同向）fast 快 slow 慢，同方向去重、移动零、链表找中点/判环、原地修改26, 27, 283, 876, 141
前后指针（间距固定）fast 先走 k 步，再同步倒数第 k、滑动窗口固定长度、链表倒数删除19, 2095, 239
多指针（三指针/多路归并）三指针分区、多数组归并颜色分类、三数之和、合并 K 数组75, 15, 23
左右边界收缩（区间调整）根据条件收缩左/右边界最小覆盖子串、长度最小子数组、字符串排列76, 209, 567

二、核心判断指南：何时用双指针？

信号特征推荐模式
数组/链表有序左右指针对撞
原地修改/去重/分区快慢指针
求两数之和/三数之和/四数之和排序 + 左右指针 / 固定一/二数 + 双指针
子数组/子串满足条件（和/积/计数）滑动窗口（动态边界）
固定长度窗口/倒数第 k前后指针间距 k
对称性判断（回文/旋转/镜像）左右指针对撞
链表找中点/判环/入环快慢指针
合并两有序数组/链表双指针归并

三、经典模板（背诵级）

1. 左右指针对撞——两数之和/三数之和

# 两数之和 II（有序数组）
def twoSum(numbers, target):
    left, right = 0, len(numbers) - 1
    while left < right:
        s = numbers[left] + numbers[right]
        if s == target: return [left + 1, right + 1]
        elif s < target: left += 1
        else: right -= 1

# 三数之和（去重核心：跳过相同值）
def threeSum(nums):
    nums.sort()
    res = []
    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]: continue
        l, r = i + 1, len(nums) - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s == 0:
                res.append([nums[i], nums[l], nums[r]])
                while l < r and nums[l] == nums[l + 1]: l += 1
                while l < r and nums[r] == nums[r - 1]: r -= 1
                l += 1; r -= 1
            elif s < 0: l += 1
            else: r -= 1
    return res

2. 快慢指针——原地去重/移动零

# 26. 删除有序数组重复项
def removeDuplicates(nums):
    slow = 0
    for fast in range(1, len(nums)):
        if nums[fast] != nums[slow]:
            slow += 1
            nums[slow] = nums[fast]
    return slow + 1

# 283. 移动零
def moveZeroes(nums):
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != 0:
            nums[slow], nums[fast] = nums[fast], nums[slow]
            slow += 1

3. 前后指针间距 k——链表倒数第 k/删除

# 19. 删除链表倒数第 N 个节点
def removeNthFromEnd(head, n):
    dummy = ListNode(0, head)
    fast = slow = dummy
    for _ in range(n): fast = fast.next
    while fast.next:
        fast, slow = fast.next, slow.next
    slow.next = slow.next.next
    return dummy.next

4. 三指针分区——颜色分类

# 75. 颜色分类（荷兰国旗问题）
def sortColors(nums):
    p0, curr, p2 = 0, 0, len(nums) - 1
    while curr <= p2:
        if nums[curr] == 0:
            nums[p0], nums[curr] = nums[curr], nums[p0]
            p0 += 1; curr += 1
        elif nums[curr] == 2:
            nums[curr], nums[p2] = nums[p2], nums[curr]
            p2 -= 1
        else:
            curr += 1

5. 滑动窗口（动态双指针）——最小覆盖/长度最小子数组

# 209. 长度最小的子数组（正数数组）
def minSubArrayLen(target, nums):
    left = 0
    cur_sum = 0
    ans = float('inf')
    for right, val in enumerate(nums):
        cur_sum += val
        while cur_sum >= target:
            ans = min(ans, right - left + 1)
            cur_sum -= nums[left]
            left += 1
    return ans if ans != float('inf') else 0

# 76. 最小覆盖子串（通用模板）
def minWindow(s, t):
    from collections import Counter
    need = Counter(t)
    window = Counter()
    left = 0
    valid = 0
    start, length = 0, float('inf')
    for right, c in enumerate(s):
        window[c] += 1
        if window[c] == need[c]: valid += 1
        while valid == len(need):
            if right - left + 1 < length:
                start, length = left, right - left + 1
            d = s[left]
            if window[d] == need[d]: valid -= 1
            window[d] -= 1
            left += 1
    return "" if length == float('inf') else s[start:start+length]

五、滑动窗口判断决策树

子数组/子串问题
    │
    ├─ 定长窗口（长度固定/可推导） → 固定滑动窗口
    │
    └─ 不定长窗口
          │
          ├─ 全正数/非负数组，求「和/积 ≥ target」最短/最长 → 单调滑动窗口（右扩左缩）
          │
          ├─ 含负数/求恰好 K 个不同值 → 前缀和+哈希表 / 恰好 K = 至多 K - 至多 K-1
          │
          ├─ 字符串匹配/排列/覆盖 → 计数滑动窗口（need/window + valid 计数器）
          │
          └─ 最大/最小值维护 → 单调队列（双端队列）

六、高频易错点速查表

易错点正确做法
三数之和去重漏掉固定数去重 if i>0 and nums[i]==nums[i-1]: continue；双指针去重 while l<r and nums[l]==nums[l+1]: l+=1
滑动窗口左边界收缩条件错while 条件满足: 更新答案再缩左；不是 if
滑动窗口计数器更新顺序错先加右/更新 valid，再缩左/减左/更新 valid
对撞指针移动策略不当容器盛水：移动短板；两数之和：根据和与 target 比较移动
快慢指针边界条件错while fast and fast.next: 而非 while fast.next:
前后指针间距 off-by-one先走 k 步，再同步走到 fast.next is None，slow 在倒数第 k+1（便于删除）
荷兰国旗 curr 指针移动错交换 2 时 p2-- 但 curr 不动（换来的新数未检查）
滑动窗口乘积除零/溢出正数数组才能用乘积滑动窗口；含 0 需分段处理
字符串滑动窗口 ASCII/Unicode用 Counter/defaultdict(int) 而非固定数组（除非明确仅小写字母）
原地修改数组返回长度题目要求返回新长度，数组前段为有效元素，后段忽略

七、复杂度速记表

模式时间空间适用前提
左右对撞O(n)O(1)有序/对称
快慢指针O(n)O(1)原地修改/链表
前后间距 kO(n)O(1)固定距离
三指针分区O(n)O(1)三值分区
滑动窗口（可变）O(n)O(k)单调性/正数/计数
滑动窗口（定长）O(n)O(k)固定长度
单调队列O(n)O(k)滑动窗口最值

八、面试实战技巧

  1. 先问是否有序：无序先排序 O(n log n)，再双指针 O(n)
  2. 明确指针语义：left/right、slow/fast、start/end、p0/curr/p2，别用 i/j
  3. 去重三步走：排序 → 固定层去重 → 双指针层去重
  4. 滑动窗口四步法：
    • 右指针扩展，更新窗口状态
    • while 窗口满足条件：更新答案，左指针收缩，恢复窗口状态
  5. 画图演示指针移动：特别是三指针分区、滑动窗口收缩
  6. 边界先跑通：空数组、单元素、全相同、目标不存在
  7. 原地 vs 新建：能原地 O(1) 空间就原地，除非必须保留原数组

一句话总结：双指针的本质是利用问题结构（有序/单调/对称/固定距离）消除冗余遍历。对撞指针用有序性，快慢指针用原地覆盖，滑动窗口用单调性/计数约束。掌握 5 大模式、3 个核心模板、1 个滑动窗口决策树，数组/链表/字符串双指针题全覆盖。
